# Programming Fundamentals - Practice Tasks (Loops & Arrays)

This repository contains C program solutions for 9 practice tasks covering basic loops, control statements, and array manipulation.

## Task Overview

- **Task 01: ATM Transactions** (`task01.c`)
  Processes repeated cash withdrawals from an initial balance of 50,000 until 0 or negative is entered.
  
- **Task 02: Student Marks** (`task02.c`)
  Calculates total, count, and average marks for valid inputs (0–100) until `-1` is entered.
  
- **Task 03: Mobile Recharge** (`task03.c`)
  Tracks balance additions until user stops or total recharge exceeds 5,000.
  
- **Task 04: Online Shopping** (`task04.c`)
  Calculates shopping total and applies a 10% discount if total exceeds 10,000.
  
- **Task 05: Restaurant Bill** (`task05.c`)
  Sums item prices and applies a 5% discount if the total exceeds 5,000.
  
- **Task 06: Login Attempts** (`task06.c`)
  Authenticates user PIN (1234) with up to 3 attempts before locking out.
  
- **Task 07: Student Marks Analysis** (`task07.c`)
  Stores 5 student marks in an array to determine total, average, highest, and lowest marks.
  
- **Task 08: Shopping Cart** (`task08.c`)
  Stores 5 product prices in an array, calculates total, and applies a 10% discount if over 10,000.
  
- **Task 09: Electricity Bill Analysis** (`task09.c`)
  Analyzes 5 household energy units using arrays, calculates bill per household (10 Rs/unit + 5% surcharge if > 500 units), and displays total units and revenue.
